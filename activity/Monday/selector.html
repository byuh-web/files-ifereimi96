CSS Questions

List out the different ways to select an item

Items can be selected using Element Selector, ID Selector, Universal Selector and Grouping Selector

What is the difference between an ID and a Class?

an ID is a unique identifier meant for a single element on a page, while a Class is a reusable identifier meant for multiple elements

What is the difference between a SPAN tag and a DIV tag?

The primary difference between div and span is how they are displayed and structured on a webpage. A div is a block-level element, while a span is an inline element

What is the difference between a DIV tag and a HEADER, MAIN, or FOOTER?

A div tag is a general container with no specific meaning, while header, main, and footer are semantic tags that describe the purpose of the content inside them.

What are the different ways to select a color?

There are different ways to select a color in CSS, including color names (red), hexadecimal codes (#ff0000), RGB values (rgb(255,0,0)), RGBA values (rgba(255,0,0,0.5)), HSL values (hsl(0,100%,50%)), and HSLA values (hsla(0,100%,50%,0.5)).
